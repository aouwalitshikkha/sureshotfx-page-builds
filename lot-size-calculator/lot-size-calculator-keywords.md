## 5. Content rules used

- **The tool is the page.** The calculator sits in the first screen with a real default result (0.50 lots), so the visitor sees the output before reading a word of copy.
- **Every claim is checkable.** Contract sizes are stated with their exceptions (gold 100 oz, silver 5,000 oz, index contracts broker-dependent). No invented pip values for exotic pairs.
- **One concept per section.** Gold, indices, platform and risk each get their own block so a query has an obvious home.
- **Word-order variants live in one table.** "lot size calculator forex", "lot size calculator gold" and "lot size calculator XAUUSD" are explained as the same tool in different words — not repeated in headings.
- **No fake precision.** The calculator rounds down to the 0.01 broker step and shows the raw value, because a lot size of 0.537 is not tradeable.
- **Risk is framed, not sold.** The page says 1–2% per trade and shows what happens at 5% — it does not promise returns.
