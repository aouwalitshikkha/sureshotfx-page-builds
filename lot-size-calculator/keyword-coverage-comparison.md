**What the old page was doing:** it ranked for the head term at position 18 and for MT4 at 8.9, but the copy was a thin wrapper around the widget. It said "lot size calculator" and "forex risk calculator" and stopped there. Gold and indices had tabs but no explanation, so 89 gold queries and 19 index queries had nothing to match. It also had no formula, no $1,000 answer and no 0.01-lot answer — the three questions that produce featured snippets.

**What the new page does differently:**

1. Turns the calculator into the H1 and the first screen, with 30 account currencies and live rates — so the tool itself earns the dwell time.
2. Adds three instrument modes with real contract maths: 16 forex pairs with quote-currency conversion, XAUUSD/XAGUSD with 100/5,000 oz contracts, and six indices with an editable value per point.
3. Adds the sections the live page lacked: the formula with three worked examples, a pip-value table by pair type, gold contract specs, index contract specs, MT4/MT5 placement, and a risk table by balance.
4. Answers the long tail directly: 0.01 lot in dollars, best size for $1,000, cent accounts, prop firms, leverage, broker differences.

**What still needs work**

1. `lot size calculator` is 3,161 impressions at position 18.2 — page two. The rebuild improves the on-page signals, but internal links from `/forex-vip-signals`, `/gold-vip-signals`, `/blog` and the pip calculator will move it more than another paragraph.
2. The 37 localized queries are ~1,500 impressions. A Spanish and German version of this page would be the highest-ROI next build.
3. `1x trade lot size calculator` (72 impressions, position 7.7) is a broker-branded query the page cannot honestly own. A note that the calculator works for any broker is already implied; do not name brokers.
4. `lot multiplier calculator` (106 impressions) is a different tool. If it keeps growing, build it separately rather than bending this page.
