## 5. Content rules used

- **The page owns the tool.** No iframe dependency: 56 pairs are computed in the page from ECB daily reference rates, and the data source is stated in the status line and a dedicated section.
- **No forecast language.** The grid reports what already happened. The FAQ says it is not a signal, not a forecast and not a liquidity map.
- **The adjacent query gets an honest answer.** `liquidity heatmap gold` is answered with "no, and here is where to go for gold sizing" rather than a colour grid pretending to be order flow.
- **Correlation is framed as risk.** The "how do you avoid stacking correlated trades?" section keeps the live page's promise but turns it into an arithmetic example, not a slogan.
- **LLM-friendly structure.** TL;DR in the first screen, question headings, tables, numbered steps, key takeaways and a 10-question FAQ with matching schema.
- **English only.** No non-English lines, no keyword insertion in other languages.
